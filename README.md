# SmartRide Design Hub

Design a modern car rental booking website called "SmartRide" with the following color scheme:

- Primary: #1a2238 (dark navy)

- Secondary: #9daaf2 (soft blue)

- Accent: #ff6a3d (vibrant orange)

- Highlight: #f4db7d (warm yellow)

Brand name: SmartRide

Tagline: "Your Smarter Way to Travel"

Pages needed:

1. Home page with navbar (logo: SmartRide), hero section with search form, features section, popular cars grid, how it works, and footer

2. Cars listing page with filters and car cards grid

3. Car details page with image gallery, car info, booking form and reviews

4. Login and Register pages

Style: Clean, professional, modern startup look. Use bold headings, readable body text, card-based layout, rounded corners (12-16px), soft shadows, and accent-colored CTA buttons (#ff6a3d). Make it mobile responsive with hamburger menu and stacked layouts.
